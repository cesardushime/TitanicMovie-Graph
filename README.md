# Titanic Movie: Social Network Analysis

The Repository holds our group project work for the course of **Social Network Analysis**.
In this project, we will analyze the social network underlying the highly popular movie "Titanic" with the help of Network Science techniques. This involves depicting the characters of the movie as nodes and their interactions as edges within the script.
